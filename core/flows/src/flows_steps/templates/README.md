# Post-meeting email assets

`meeting-followup.html` and `meeting-followup.parts.json` are generated by React Email source
in `core/flows/email-design/`. Run `pnpm build` and `pnpm check` there after editing the design;
do not edit these generated files directly.

`email_design.py` validates artifact URLs and substitutes escaped meeting copy into these assets.
`tina-logo.png` is the rasterized original logo from `clients/terminal/public/tina-logo.svg`.
The SMTP adapter attaches it inline with `Content-ID: <tina-logo@tina>`.
